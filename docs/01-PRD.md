---

## 1. 背景与问题

### 1.1 目标站点

- **yande.re** 与 **konachan.com** 均为 moebooru 架构，提供公开 JSON API：搜索、榜单、标签、评论。
- 两站内容高度重合但各有独立图库，用户通常两个都用。
- 现有 Windows 客户端为 appx / UWP，受 AppContainer 沙箱、后台挂起、网络隔离、商店审核限制，且本机 konachan 的 appx 已无法访问。

### 1.2 网络现状（已实测）

| 事实 | 影响 |
|---|---|
| konachan.com 由 Cloudflare 托管 | 非浏览器请求返回 `403 Just a moment`，必须持有 `cf_clearance` |
| 本机对 konachan.com 的 DNS 解析被污染（返回 Facebook/Twitter 的 IP） | 客户端不能依赖系统 DNS |
| yande.re 为独立服务器（`198.251.89.183`，图床 `198.251.88.76`） | 无 Cloudflare，仅需正确解析 |
| konachan 真实 A 记录 `104.21.4.105` / `172.67.131.252`，AAAA `2606:4700:3030::ac43:83fc` 等 | IP 会变动，需可配置 |

### 1.3 结论

客户端必须**自己**解决两件事：域名解析覆盖、Cloudflare 通行证。这是本产品存在的核心理由，也是与普通 booru 客户端的差异点。

## 2. 目标

| 编号 | 目标 | 衡量方式 |
|---|---|---|
| G1 | 不配置系统 hosts 也能访问两站 | 默认配置下 yande / konachan 搜索均可用 |
| G2 | 完成"搜图 → 看图 → 标记 → 下载 → 收藏"闭环 | 全流程无阻塞 |
| G3 | 安装简单 | 单 exe，per-user 安装，无需管理员 |
| G4 | 数据完全本地 | 无账号、无云同步、无遥测 |

## 3. 范围

**In scope**

- 标签搜索、标签联想、榜单浏览
- 缩略图网格、大图查看器
- 已看 / 已下载 / 已收藏 三态标记
- 批量下载（队列、断点续传、md5 校验）
- 本地收藏、搜索历史
- 网络设置（代理、IP 映射、UA）与连通性诊断
- Windows x64 打包分发

**Out of scope（首版）**

- 上传、评论、投票等写操作
- 账号登录与云端同步（两站均为公开 API，无个人账号数据）
- macOS / Linux / 移动端
- danbooru、gelbooru、e-hentai 等第三方站点
- 内置 VPN / 翻墙能力

## 4. 用户与场景

**目标用户**：在 Windows 上浏览 yande.re / konachan.com 的重度用户，已有收藏与下载习惯，对网络问题有一定认知。

| 场景 | 描述 | 对应需求 |
|---|---|---|
| S1 找图 | 输入多个标签组合，滚动浏览，点开看大图 | FR-02 / FR-03 / FR-07 |
| S2 逛榜单 | 看今日/本周/本月热门 | FR-05 |
| S3 存图 | 按标签+评分批量下载，校验完整性 | FR-10 / FR-11 |
| S4 清库存 | 只看没看过的图，看过的自动变暗 | FR-08 / FR-09 |
| S5 排障 | konachan 打不开，用内置诊断定位 | FR-17 |

## 5. 功能需求

优先级定义：P0 = 首版必须；P1 = 第二版；P2 = 后续。

| 编号 | 功能 | 优先级 | 描述 | 验收要点 |
|---|---|---|---|---|
| FR-01 | 多站点 | P0 | 顶栏切换 yande.re / konachan.com，各自独立会话与收藏 | 切换后 cookie、缓存、筛选互不影响 |
| FR-02 | 标签搜索 | P0 | 支持空格 AND、`-tag` 排除、`rating:s/q/e`、`score:>=N`、`order:score/fav/random`、`id:` | 语法解析正确，结果与网页一致 |
| FR-03 | 无限滚动与深度翻页 | P0 | 触底加载；超过 page 上限时改用 `id:<last>` 游标 | 连续滚动 1000+ 条不重复、不丢条 |
| FR-04 | 标签联想 | P0 | 输入 ≥2 字符、300ms 防抖，本地缓存优先 | 候选含类型与作品数，键盘可选 |
| FR-05 | 榜单 | P0 | 热门（1d/1w/1m）、日榜、周榜、月榜，可选日期 | 四个入口均可加载且可翻页 |
| FR-06 | 缩略图网格 | P0 | 虚拟化瀑布流，只加载 preview/sample | 1000 项滚动流畅，内存稳定 |
| FR-07 | 大图查看器 | P0 | 缩放、拖动、上下张、sample↔file 切换 | 打开 <1s 显示 sample，原图后台加载 |
| FR-08 | 已看标记 | P0 | 点开即标记；列表以透明度+角标呈现 | 重开应用状态不丢；见设计文档 |
| FR-09 | 隐藏已看 | P0 | 列表可过滤已看项，自动补页 | 开启后一屏仍能填满 |
| FR-10 | 下载 | P0 | 单张、整页批量、按筛选批量 | 文件 md5 与 API 一致 |
| FR-11 | 下载队列 | P0 | 并发 1–6、暂停/恢复/取消、断点续传 | 中断后恢复不重下已完成部分 |
| FR-12 | 收藏 | P0 | 本地收藏，可按站点/标签筛选 | 收藏与已看状态独立 |
| FR-13 | 设置 | P0 | 下载目录与命名、并发、代理、IP 映射、UA | 修改后即时生效 |
| FR-14 | R18 默认关闭 | P0 | 默认请求附带 `-rating:e`；开启需确认 | 默认搜索结果无 explicit |
| FR-15 | 三态角标 | P0 | 已看 ✓ / 已下载 ↓ / 已收藏 ★ | 三者可叠加显示 |
| FR-16 | Cloudflare 通行 | P0 | 遇 403 自动开隐藏窗口取 `cf_clearance` 并重试 | 首次访问 konachan 无需手动干预 |
| FR-17 | 连通性诊断 | P1 | 一键检测 DNS、TCP 443、TLS、CF 状态、代理 | 输出结论与建议 |
| FR-18 | 自动更新 | P1 | electron-updater + 手动检查 | 更新失败不影响使用 |
| FR-19 | 搜索历史 | P1 | 记录最近 50 条查询 | 可点击复用、可清空 |
| FR-20 | 标签黑名单 | P1 | 全局屏蔽指定标签 | 所有站点生效 |
| FR-21 | danbooru 适配 | P2 | 需要 API key | 不影响现有站点 |

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 冷启动 ≤ 3s；搜索首屏 ≤ 2s（网络正常）；1000 项滚动不掉帧 |
| 网络 | 每站点限速 1–2 req/s；429/5xx 指数退避；超时 20s |
| 可靠 | 下载失败可重试；数据库写入事务化；异常不导致白屏 |
| 安全 | `contextIsolation: true`、`nodeIntegration: false`、CSP、文件名清洗 |
| 合规 | 标识 UA、遵守站点 ToS、不做全站爬取、不内置分发内容 |
| 可用性 | 中文界面、暗色主题、键盘可完成核心操作 |
| 可维护 | 适配器可扩展；IPC 类型化；单元测试覆盖解析与适配层 |

## 7. 版本验收标准

1. 全新安装、**未配置系统 hosts** 时，yande.re 与 konachan.com 搜索均可用。
2. konachan 首次访问遇 Cloudflare 挑战可自动通过，无需用户手动开浏览器。
3. 搜索 → 点开 → 已看标记 → 下载 全流程可用；重开应用后已看状态保留。
4. 批量下载 100 张，md5 校验全部通过。
5. 开启"隐藏已看"后，连续滚动仍能填满视口。
6. 断网时展示明确错误态，恢复网络后可重试。
7. NSIS x64 安装包可在纯净 Windows 11 上免管理员安装并启动。

---

## 8. 假设与约束

- Cloudflare 边缘 IP 会变化，应用需允许用户编辑映射表，不能写死。
- 应用**不能**绕过网络层完全封锁；若到 Cloudflare 的 TCP 均不可达，只能依赖系统代理。
- 站点 ToS 禁止大规模抓取，应用限速且不提供全站爬取功能。
- 无账号体系，所有状态（已看、收藏、历史）仅存本地。
- 仅支持 Windows x64，暂不提供 32 位与 ARM 版本。

---

## 9. 风险

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| Cloudflare 挑战升级（如 Turnstile 交互式） | 中 | konachan 不可用 | 支持用户手动打开验证窗口；保留浏览器 cookie 导入 |
| CF 边缘 IP 变更 | 高 | 解析失败 | IP 映射可编辑 + 诊断面板提示 + 一键测速选优 |
| 站点限流或封 UA | 中 | 搜索失败 | 严格限速、UA 可配、退避重试 |
| 图片体积大导致内存压力 | 中 | 卡顿 | 虚拟列表 + 及时释放查看器图片 |
| 内容合规 | 低 | 分发受限 | 默认关闭 R18、不预置内容、仅个人使用 |
