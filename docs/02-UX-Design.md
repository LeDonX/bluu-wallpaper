## 1. 信息架构

```
目标外壳（T-38~，见 10-UI-Shell-Plan）：
```

> 当前实现（2026-11-06/T-60 核对）：`App.tsx` 提供顶部五页导航（首页 / 每日壁纸 / 收藏 / 下载 / 设置）。榜单页已并入首页（T-59 / DR-088），诊断已并入设置（T-60 / DR-089）；首页工具条同时承载站点切换、榜单类型（热门/日/周/月）与日期；页面常驻挂载、切换仅改变可见性；「每日壁纸」按能力表出现（DR-076 / 077），1024 宽窗口下导航自动换行。首页内自带搜索框、chip、隐藏已看开关、最小分辨率筛选与 R18 过滤提示；代理不可达回退直连时在导航下方显示横幅（DR-039）。顶栏统一 `SiteSwitcher`、侧栏与状态栏尚未实现；入口由 `SITE_CAPABILITIES` 能力表驱动：搜索 3 站（yande / konachan / wallhaven）、榜单类型 2 站（yande / konachan）、收藏与每日壁纸按各自能力展示（T-48~T-53 / DR-070 / 077；pexels 已移除，DR-084）。

页面清单：

默认窗口 1080×720；启动时按主屏可用区域（workArea）的 90% 收敛，小屏或高 DPI 下不会超出屏幕。最小窗口 800×560，允许用户缩得更小。暗色主题为默认。

### 1.1 品牌与角色

- 产品名 **LePic**（英文品牌，不设中文名；来源为 LeDon + picture），角色只出现在空态、加载、错误与关于页，图墙保持克制；角色形象与命名归 T-43 重新确定（旧蓝鲨「噗噗」设定不再沿用）。
- 色板：角色蓝 `#4C8DFF`、浅蓝 `#B9DDFF`（沿用强调色）、肚皮 `#F2F7FF`、深底 `#0F1115`。
- 加载动效：泡泡上升映射字节进度，100% 时破裂（约 150ms）；`prefers-reduced-motion` 下改为静态。
- 角色与图标须原创，不得描摹既有蓝鲨卡通形象；图标/角色资源归 T-43。

## 2. 搜索页

### 2.1 输入

- 单行输入框，回车提交；支持多标签堆叠为 chips。
- 提交时解析为结构化查询（语法见 2.4），非法语法在输入框下方红字提示，不发起请求。
- 右侧"隐藏已看"开关为独立 toggle，不写进查询串。
- 站点切换：标题右侧按能力表展示具备 `search` 能力的站点（yande.re / konachan.com / wallhaven.cc，T-53 / DR-077）。切站即切换站点视图，与普通页面切换一致：不保留上一站点的列表，页面直接回到新站点首页（yande / konachan / wallhaven 均为 24 小时热门，DR-085 / DR-087），不自动重搜搜索框里的旧关键词；需要在新站点搜索时回车提交（DR-086）。loading 期间切站不阻塞，旧站点在途响应按请求序号作废，避免慢站点锁死切站入口（DR-079）。
- 首页：应用启动即以默认站点（yande）的 24 小时热门填充结果区，不再停留在"输入标签开始搜索"空态；空查询提交同样加载当前站点首页（`popular_recent period=1d`，konachan 当日榜在当天结束前几乎为空，故与 wallhaven 统一为 24 小时热门，DR-087）；wallhaven 首页可继续翻页，yande / konachan 热门为单页、不再请求后续页；首页不写入搜索历史（DR-085）。
- 需要密钥的站点（wallhaven）未配置或读取失败时，tab 置灰不可选，悬浮提示「未配置 API key，请在设置 → 图库服务中填写」。
- 最小分辨率筛选：在有 `resolutionFilter` 能力的站点（yande / konachan / wallhaven）显示下拉（全部 / ≥1920×1080 / ≥2560×1440 / ≥3840×2160），选中后以 `width:>=N` 拼入查询并重搜；Bing 无搜索入口。
- 标签联想仅对具备 `suggest` 能力的站点启用（yande / konachan）；切站时清空联想状态。

### 2.2 结果区

- 虚拟化瀑布流，列宽 200–260px 自适应；卡片高度按原图比例计算并 clamp 140–420px；卡片只加载 `preview_url`，sample 与原图由查看器打开时按需加载（DR-028），网格不做悬停预取。
- 卡片信息条：评分、尺寸、rating 色点、三个状态角标。
- 触底 300px 触发加载下一页；底部加载提示为固定高度常驻槽位，文案切换不改变滚动高度，也不覆盖末行卡片（DR-090）。
- 顶部显示 `共 N 条 · 已显示 M 条`（N 为站点返回的总数估计，若接口不提供则显示已显示条数）。

### 2.3 分页策略

1. moebooru 站点（yande / konachan）前 100 页用 `page=N`（每页 100）。
2. 超过后切换到游标模式：`tags=原查询 id:<当前页最小 id>`，按 `id` 降序，避免 page 上限。
3. wallhaven 仅支持 `page`，不使用 `id:` 游标；收到 `lastId` 时回落第 1 页（T-50）。
4. 去重以 `(site, post_id)` 为准，合并到已有列表。
5. 追页失败或合并后无新增条目即停止自动追页（DR-090）：失败保留错误条与「重试」，继续滚动不再自动重试；站点深翻返回重复页时视为到底，避免「正在加载更多」反复闪烁。

### 2.4 搜索语法（沿用原站）

| 语法 | 含义 |
|---|---|
| `tag1 tag2` | AND |
| `-tag` | 排除 |
| `rating:s` / `q` / `e` | 分级 |
| `score:>=100` | 评分比较 |
| `order:score` / `fav` / `random` | 排序 |
| `id:123456` | 精确指定 |
| `width:>=1920` | 尺寸比较 |

R18 关闭时，若用户未显式写 `rating:`，自动附加 `-rating:e`，并在界面提示"已过滤 R18（设置中可开启）"。

标签黑名单（T-37 / DR-056）：设置页可录入排除标签（每行或空格分隔，最多 100 个）。搜索时逐项以 `-tag` 追加到站点查询（与用户已写的同名 `-tag` 去重，大小写不敏感），命中后提示"已按标签黑名单排除 N 个标签"；榜单端点不支持 tags，改为在返回结果上本地过滤，提示"已按标签黑名单过滤 N 张"。榜单计数只包含通过 R18 过滤后又被黑名单丢弃的条目。

多源映射（T-50 / T-53）：同一套语法按站点能力翻译——`rating:` 在 wallhaven 映射为 `purity` 位（R18 关闭即 SFW），`score:` 原样保留，`order:` 映射为 wallhaven `sorting`，`width:` 映射为 `atleast`；Bing 不支持关键词搜索。pexels 已于 DR-084 移除。

### 2.5 空态 / 错误态

| 状态 | 呈现 |
|---|---|
| 无结果 | 插图 + "没有匹配的图片" + "试试减少标签" |
| 网络错误 | 错误卡片 + 错误码 + 下一步引导 + "重试"（诊断已随 T-34 提供，入口在「设置 → 诊断」，T-60；错误卡片暂不带跳转按钮，DR-052 / DR-067） |
| 被 CF 拦 | 搜索/榜单首屏显示"正在通过 Cloudflare 验证，首次访问可能需要 10~25 秒，请稍候"，不暴露技术细节；启动预热命中时通常一闪而过；失败后错误卡片引导稍后重试或重启应用（DR-068） |
| 限流 | 自动退避；达到重试上限时错误卡片提示"请求过快，已自动降速，请稍后重试"（07 DR-052） |
| 未配置密钥 | 站点 tab 置灰（见 §2.1）；若仍触发请求，错误卡片按 `CONFIG` 引导去设置页「图库服务」填写，文案含站点名（如"Wallhaven API 密钥无效，请在设置中重新填写"） |
| 无对应能力 | 无榜单 / 联想 / 每日壁纸能力的站点不展示对应入口，不发请求；直接调用返回 `CONFIG` |

> 错误引导按错误码统一由 `shared/error-guidance.ts` 生成：网络/超时→检查网络与代理；解析失败→检查查询语法；本地读写→可重试或重启；下载失败→下载页单条重试；配置无效→去设置页检查。

## 3. 标签联想

- 输入 ≥ 2 字符、停止输入 300ms 触发。
- 数据源优先级：本地 `tag_cache`（命中前缀）→ 远端 `/tag.json?name=prefix*&limit=10`。
- 每项显示：标签名、类型（artist / copyright / character / general）、作品数。
- 键盘 `↑ ↓` 选择、`Tab` 补全为 chip、`Esc` 关闭；回车或点击搜索提交时同时关闭下拉。

## 4. 首页榜单模式（原榜单页，T-59 / DR-088）

> 搜索与榜单合并为「首页」一个页签：榜单类型与期选择作为首页工具条，仅在未提交关键词（首页模式）且当前站点具备 `rankings` 能力时出现；提交关键词后切换为搜索结果，清空后回车回到首页模式。

| 类型 | 选择方式 | 请求 |
|---|---|---|
| 热门 | 无日期 | `/post/popular_recent?period=1d` |
| 日榜 | 日期选择器 | `/post.json?tags=date:<日期> order:score`（可翻页） |
| 周榜 | 年 + 周数（ISO 8601，周一为一周开始） | `/post.json?tags=date:<该周周一>..<该周周日> order:score`（可翻页） |
| 月榜 | 年 + 月份 | `/post.json?tags=date:<当月1日>..<当月月末> order:score`（可翻页） |

- 首页默认「热门」（24 小时），应用启动即加载；榜单类型和期选择与站点切换同处一个工具条。
- 期选择仅对日/周/月榜显示，且不可选未来期：日榜 `max=今天`；周榜当年只到当前周、过去年份可选全年；月榜当年只到当前月。
- 切到日/周/月榜时默认展示**上一个完整周期**（昨天 / 上周 / 上月），避免把进行中的当天、本周、本月当作完整期导致结果偏少（DR-091）；当前期仍可手动选择。
- 计数行同时显示当前期（如 `日榜 · 2026-11-05`、`周榜 · 2026 年第 45 周`、`月榜 · 2026-10`）。
- 结果区复用首页网格组件。
- 热门固定 `period=1d` 且站点只返回 40 条（07 DR-008 / DR-041 / DR-087），不提供日期与翻页；日/周/月改用 `/post.json` 的 `date:` 区间 + `order:score`，返回当期全部作品并支持继续滚动翻页（DR-092）；合并后无新增即停止。
- 榜单类型只展示具备 `rankings` 能力的站点（当前为 yande.re / konachan.com，T-53 / DR-077）；切到 wallhaven 时该组控件隐藏，首页显示 24 小时 toplist。切站后按当前榜单类型与期选择重载（DR-088）。
- 查看器内点击标签直接在首页执行该标签查询，沿用当前站点（07 DR-041 / DR-057）。

## 5. 查看器

### 5.1 打开流程

`点击卡片 → 立即标记已看 → 并行加载 sample 与 file → sample 就绪后占位 → file 就绪后无缝替换`

- 打开后**始终自动懒加载原图**，不设体积阈值，也不提供“加载原图”按钮。
- 两种图片都经主进程流式下载（`images:fetch`），渲染层只接收字节并生成 `blob:` 展示；切图时按需加载，内存缓存最多 3 张。
- 加载进度：预览图进度在预览区居中，只显示一条无文本的进度条；原图进度固定在预览区右上角，显示百分比与“已加载 / 总量”，预览图就绪后位置不变。有 `Content-Length` 时显示确定进度；缺失时预览条与原图条均退化为不确定进度。
- 原图就绪后直接替换预览图（同一 `<img>` 切换 `blob:` 地址），不叠加渲染两张图。
- 失败：sample 失败且原图未就绪 → 画布中心错误提示（右上角原图进度继续展示）；原图失败但 sample 可用 → 保留 sample 并在右上角提示“原图加载失败”。
- 不预取相邻图片，避免无意义流量。

### 5.2 布局

- 图片区居中，支持滚轮缩放（以鼠标为锚点）、拖动、双击复位。缩放范围为默认适应尺寸的 100%–400%：可放大，但不能缩小到比默认更小；缩到 100% 等价于重置缩放（偏移一并归零）。
- 拖动有边界：放大后最多拖到图片四边与预览区四边对齐，不能无限拖出预览区；100% 时偏移始终为 0。
- 右侧信息栏（可收起）：尺寸、文件大小、评分、rating、来源、上传时间、标签（点击即搜，标签 chip 旁另有「＋关注」/「已关注」按钮，DR-069）、操作按钮（下载 / 收藏）。"复制链接"与"在浏览器打开"尚未实现（DR-024）。
- 来源字段多源差异（T-53 / DR-084）：Bing 显示版权文案；yande / konachan / wallhaven 显示「来源」。来源含 URL 时可点击外链。
- 底部：`已看 3 次 · 首次 2026-11-01`。

### 5.3 快捷键

| 键 | 行为 |
|---|---|
| `← / →` | 上一张 / 下一张（同时标记已看） |
| `Space` | 缩放复位 / 适应窗口 |
| `+ / -` | 放大 / 缩小 |
| `D` | 下载当前图 |
| `F` | 收藏 / 取消收藏 |
| `O` | 浏览器打开原图（未实现，DR-024） |
| `Esc` | 关闭查看器 |

## 6. 已看标记（核心差异化功能）

### 6.1 标记规则

| 事件 | 标记 |
|---|---|
| 点击缩略图进入查看器 | ✅ |
| 查看器内切换上一张/下一张 | ✅ 逐张 |
| 从收藏页、下载页打开 | ✅ |
| 鼠标悬停、列表滚动出现 | ❌ |
| 下载完成 | ❌（记入"已下载"，独立状态） |
| 图片加载失败 | ✅（用户已表达查看意图，避免重复点击） |

### 6.2 视觉规范

不能只用颜色区分（色弱不友好），采用**透明度 + 图标**双编码：

| 状态 | 缩略图 | 角标（右上角，18×18，圆角 4，半透明底） |
|---|---|---|
| 已看 | `opacity: 0.55`，`filter: saturate(0.8)` | —（不再显示 ✓，变暗已足够） |
| 已下载 | 正常 | ↓ 绿色 `#3FA96B` |
| 已收藏 | 正常 | —（★ 在左上角常显） |
| 已看 + hover | `opacity: 1` | — |
| 组合 | 角标横向排列，最多 3 个 | — |

- 卡片右下角保留评分角标，不与之重叠。
- 右上角状态角标与多选勾选框默认隐藏，卡片 `hover` / `focus-within` 时才显示；左上角收藏 ★ 常显、未收藏 ☆ 仅悬停显示（DR-039 / DR-045）。
- 已看不再渲染 ✓ 角标，仅用缩略图透明度 + 饱和度表达（DR-045）。
- 加载态用骨架块，不使用"已看"样式，避免误判。

### 6.3 "隐藏已看"过滤

本地状态，服务器无感知，因此需**自动补页**：

```
while (可见项 < 一屏) and (连续补页 < 5):
    fetch(nextPage)
    append(filter(not viewed))
if 连续 5 页均无未看项:
    show("已跳过 N 张已看过的图片")
```

- 过滤开启时，顶部提示"已过滤 X 张已看"。
- 关闭过滤立即恢复完整列表（已加载数据不丢弃）。

### 6.4 清除记录

设置页提供"清除浏览记录"，选项：当前站点 / 全部。二次确认，操作后列表即时刷新。

## 7. 下载

### 7.1 入口

- 查看器 `D` 键或按钮：单张。若该帖存在独立 JPG 压缩版（PNG 原图），信息栏的“下载 / 重新下载”按钮带 `▾`，点击展开二级菜单，可选“原图 · 体积”或“较小 JPG · 体积”后入队；点空白处或 Esc 收起菜单。JPG 原图帖子没有独立压缩版，按钮点击直接下载；`D` 键未指定格式时使用设置页默认格式（DR-051）。
- 网格多选默认关闭；在卡片上右键选择"多选"开启；多选期间卡片仅在已选中时显示勾选框，未选中项不随悬停揭示任何图标；`Shift` 连选、`Ctrl` 点选；选中态以 `site:id` 记录，滚动回收不丢失；退出多选清空选中（DR-039 / DR-046 / DR-048）。
- 多选开启后，点击卡片任意位置即切换选中（`Shift` 连选），不再打开查看器；多选期间不渲染收藏按钮，退出多选后恢复独立点按（DR-047 / DR-048 / DR-049）。
- 多选期间卡片只常显已选中项右上角的勾选框；收藏 ☆/★、状态角标与 hover/focus 揭示全部关闭，hover 也不再有边框强调，避免最后点击的卡片因保持焦点而残留图标（DR-048）。
- 多选只承担勾选，不承担收藏：多选期间**不渲染**左上角收藏按钮（不是仅隐藏），退出多选后才恢复；`hover` 规则的选择器权重已按多选态修正，未选中项悬停不会再露出 ☆ 或勾选框（DR-049）。
- 多选期间的操作（已选数量、预估体积、下载选中、退出多选）用悬浮条呈现，不占据结果页布局（DR-046）。
- 批量下载入口只针对选中项；不再提供"下载全部结果"按钮（DR-046）。

### 7.2 任务状态机

```
queued → downloading → verifying → done
                ↘ paused ↗
                ↘ failed（可重试）
```

### 7.3 命名模板

默认：`{md5}.{ext}`（下载文件直接保存在设置的下载目录下，不再生成站点子目录，07 DR-064）

| 变量 | 说明 |
|---|---|
| `{site}` | yande / konachan |
| `{rating}` | safe / questionable / explicit |
| `{artist}` | 首个 artist 标签，无则 `unknown` |
| `{copyright}` / `{character}` | 对应标签 |
| `{id}` / `{md5}` / `{ext}` | 标识与扩展名 |

非法字符（`/ \ : * ? " < > |` 与控制字符）替换为 `_`，`..` / `.` 段同样替换为 `_`；渲染结果超过 120 字符时回落到紧凑路径 `{md5}.{ext}`。

模板中未定义的变量原样保留（如 `{foo}` 会留在文件名中）；`artist` / `copyright` / `character` 取该类型首个标签，缺失时统一为 `unknown`。模板可在设置中修改（T-30）。

**下载格式（DR-051）**：查看器单张下载时，存在多个版本则“下载 / 重新下载”按钮展开二级菜单，选项为“原图 · 体积”或“较小 JPG · 体积”；JPG 版本使用站点 `jpeg_url`，`jpeg_url` 与 `file_url` 相同或 `jpeg_file_size` 为 0 时视为没有独立版本，按钮直接下载原图。扩展名随实际下载地址生成，因此同一图片可同时存在 `.png` 与 `.jpg` 两个文件。批量下载沿用设置页的“批量默认格式”（原图 / 较小 JPG），默认原图。

### 7.4 去重与冲突

1. 先查同一站点是否已成功下载同一实际下载地址（数据库 `download_tasks.status='done'` 且 `task.url` 与本次变体地址一致；原图与 JPG 共享站点 md5，不能只按 md5 判定，DR-051）。
2. 再查目标路径是否存在同名文件（同时避让同批/存量任务已占用的目标路径）。
3. 存在且大小一致 → 跳过；不一致 → 文件名追加 ` (1)`（空格 + 序号，最大 ` (99)`）。
4. 目录已切换时（DR-062）：已完成任务若不在当前下载目录下，重新下载并迁到新目录，旧目录中的文件保留，不视为"已下载"而跳过。

### 7.5 批量确认

超过 50 张时弹确认框：数量、预估体积（按 `Post.fileSize` 求和，缺失计为未知）。目标目录当前不展示；`settings:get` 已能返回下载目录，但批量确认尚未接入（07 DR-038 / T-30）。

入队前目录校验（T-28 现场反馈 / DR-059）：任何下载（单张、批量、重新下载）在入队前检查设置页的下载目录。目录不存在、盘符未接入或指向文件时，弹系统目录选择框；选中后写回设置并继续入队，取消则提示"未选择下载目录，下载未开始"。未配置自定义目录时使用应用默认目录，缺失会自动创建，不弹框。选中写回后，设置页草稿通过 `settings:destination-changed` 广播同步显示新目录（DR-061）。

设置页下载目录（DR-061）：输入框右侧提供「选择文件夹…」，点按弹系统目录选择框；当前输入值可用时对话框从该目录打开，为空或不可用则回退到配置文件目录/应用默认目录。选择结果先写入草稿，沿用原有"保存下载设置"按钮落盘；取消不修改任何内容。

写入时目录失效（DR-063）：目录"可用"判定除存在且是文件夹外，还要能写入（创建并删除临时探针文件）。用户删掉下载文件夹后，Windows 可能立即重建同名"已知文件夹"，仅查存在会误判；此时入队会弹选择框。若删除发生在下载过程中（写 `.part` 时报 `ENOENT`/`EPERM` 等），任务不直接落成"下载失败，请重试"，而是弹目录选择框：选中后把该任务迁到新目录（保留原有相对路径，默认模板下只有文件名）并重新排队；取消才落失败，文案为"下载目录不可用，请重新选择目录"（磁盘写满为"磁盘空间不足，请清理或更换下载目录"）。网络与 HTTP 错误不弹目录框。

## 8. 收藏

收藏页分「收藏作品」与「关注动态」两个子页签；「关注动态」右侧显示未读总数角标（`favorites-page__badge`，0 时不显示）。

### 8.1 收藏作品

- 网格展示，按站点分组 tab，覆盖全部 4 个站点（yande / konachan / wallhaven / bing，T-53 / DR-077）；空分组不置灰，只显示空态。
- 支持按标签二次筛选、按收藏时间/评分排序。
- 收藏数据仅本地，不请求站点（避免触发限流）。收藏快照保存 `source`，保证 bing 版权在收藏页与详情页一致（迁移 008，T-53 / DR-077）。
- 标签二次筛选与排序仅在「收藏作品」子页签显示。

### 8.2 关注动态（T-47 / DR-069）

- 关注对象是**标签**，画师标签同样可关注（如 `koh_(minagi_kou)`），一条关注对应一个 `(站点, 标签)` 组合。
- 入口两处：
  - 关注动态工具栏「添加关注」：输入标签回车添加。非法标签（空、含空白、超长、以 `-` 开头、含 `:`）与黑名单标签内联报错；重复添加复用已有记录，不重复拉取。
  - 查看器标签 chip 旁「＋关注」小按钮：已关注显示「已关注」（点击无副作用），标签本体点击仍执行搜索。失败原因（如黑名单）显示在标签区内联提示；首次拉取失败保留订阅并提示"首次拉取失败，稍后刷新重试"。
- 两种页签可切换：
  - **时间轴**：按作品「首次发现」的本地日期分组，日期倒序；只显示有新增作品的日期（跳过空日期）。每个日期一条横向卡片行，列数随窗口宽度自适应；当日作品超出列数时，行末提供「查看全部 N 张」，点击就地展开该日全部作品（同一时间只展开一个日期），展开后可「收起」。同一作品被多个关注命中只显示一次（按 `(site, post_id)` 去重），未读取并集。
  - **标签**：每个关注占一行，行头显示 `#标签`、未读数、作品数与「全部已读」「取消关注」；行内同样为宽度自适应的单行卡片，超出时行末提供「查看更多」，点击就地展开该标签全部作品并可「收起」。同一时间只展开一个标签行。
- 未读规则：首次成功拉取到的作品视为已读；之后新出现的作品标未读。打开任一作品即清该条未读，作品卡片右上角红点消失；标签行「全部已读」一次清空该标签的未读。
- 刷新：每次启动应用后自动静默刷新全部关注，也可在工具栏「刷新」手动触发。刷新完成后页面自动重载并更新未读计数。
- 每个关注只保留最近 100 条作品快照；取消关注时级联删除该关注的关联记录，不影响已收藏作品。

## 10. 诊断（设置内分组，P1）

> T-60 / DR-089：诊断不再占用顶部导航，改为设置页最后一个分组「诊断」，控件、结果与复制报告行为不变；原独立页面文件已删除（`DiagnosticsPanel` 组件化）。

一键检测，逐项输出结果与建议：

| 检测项 | 判定 | 建议文案 |
|---|---|---|
| DNS 解析 | 应用内映射是否命中；未命中时系统解析是否返回 IPv4 | "请检查 IP 映射条目，或关闭映射后重启应用" / "请检查网络连接后重试" |
| TCP 443 | 映射 IP（未映射时为域名）是否可连，5s 超时 | "IP 不可达，请更换映射 IP 或配置代理" |
| TLS | 证书链与站点主机名校验是否通过，8s 超时 | "证书异常，可能存在中间人；请检查代理或关闭 IP 映射后重试" |
| Cloudflare | session 中是否已有 `cf_clearance`；yande 不适用 | "首次访问 konachan 时应用会自动验证；仍失败请重启应用后重试" |
| 代理 | 已配置模式与实际生效模式，回退时显示原因 | 复用回退原因（如"代理不可达，已回退直连"） |
| 下载目录 | 存在、是目录、可写（与 DR-063 探针一致）；未配置的默认目录缺失时先按首次下载行为创建再判定 | "请在设置页重新选择可写的下载目录" |

- 六项检查全部在主进程执行，逐项独立结算：单项失败只标记该行，不中断整份报告；每行附耗时。
- 诊断只读，不修改设置；不主动触发 Cloudflare 挑战窗口（避免额外等待与隐藏窗口副作用），因此未取得 `cf_clearance` 时只给警告与建议，不提供"手动验证"按钮（`cf:manualVerify` 仍为独立任务，03 §7）。
- "一键复制报告"输出站点、时间、汇总与逐项结果/建议的纯文本，用于反馈问题。
