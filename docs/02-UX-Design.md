## 1. 信息架构

```
顶栏： [站点切换] [搜索框] [隐藏已看] [R18 指示] [设置]
侧栏(可选)： 当前查询标签 / 热门标签
主区： 搜索 | 榜单 | 收藏 | 下载
底部状态栏： 队列状态 · 当前站点限速 · CF 状态
```

页面清单：

| 页面 | 入口 | 主要内容 |
|---|---|---|
| 搜索 | 默认 | 查询输入、结果网格、分页加载 |
| 榜单 | 顶栏 | 类型/日期选择、结果网格 |
| 查看器 | 点击缩略图 | 大图、元信息、标签、操作按钮 |
| 收藏 | 顶栏 | 本地收藏网格 |
| 下载 | 顶栏 | 任务列表、进度、失败重试 |
| 设置 | 顶栏 | 常规/网络/下载/隐私/诊断 |

默认窗口 1280×860，最小 1024×720。暗色主题为默认。

### 1.1 品牌与角色

- 产品名 **Bluu / 蓝噗**，角色为原创圆身蓝鲨「噗噗」；角色只出现在空态、加载、错误与关于页，图墙保持克制。
- 色板：角色蓝 `#4C8DFF`、浅蓝 `#B9DDFF`（沿用强调色）、肚皮 `#F2F7FF`、深底 `#0F1115`。
- 加载动效：泡泡上升映射字节进度，100% 时破裂（约 150ms）；`prefers-reduced-motion` 下改为静态。
- 角色与图标须原创，不得描摹既有蓝鲨卡通形象；图标/角色资源归 T-43。

## 2. 搜索页

### 2.1 输入

- 单行输入框，回车提交；支持多标签堆叠为 chips。
- 提交时解析为结构化查询（语法见 2.4），非法语法在输入框下方红字提示，不发起请求。
- 右侧"隐藏已看"开关为独立 toggle，不写进查询串。

### 2.2 结果区

- 虚拟化瀑布流，列宽 200–260px 自适应；卡片高度按原图比例计算并 clamp 140–420px；卡片显示 `preview_url`，hover 300ms 后预取 `sample_url`。
- 卡片信息条：评分、尺寸、rating 色点、三个状态角标。
- 触底 300px 触发加载下一页；加载中显示底部骨架条。
- 顶部显示 `共 N 条 · 已显示 M 条`（N 为站点返回的总数估计，若接口不提供则显示已显示条数）。

### 2.3 分页策略

1. 前 100 页用 `page=N`（每页 100）。
2. 超过后切换到游标模式：`tags=原查询 id:<当前页最小 id>`，按 `id` 降序，避免 page 上限。
3. 去重以 `post_id` 为准，合并到已有列表。

### 2.4 搜索语法（沿用原站）

| 语法 | 含义 |
|---|---|
| `tag1 tag2` | AND |
| `-tag` | 排除 |
| `rating:s` / `q` / `e` | 分级 |
| `score:>=100` | 评分比较 |
| `order:score` / `fav` / `random` | 排序 |
| `id:123456` | 精确指定 |
| `width:>=1920` | 尺寸比较 |

R18 关闭时，若用户未显式写 `rating:`，自动附加 `-rating:e`，并在界面提示"已过滤 R18（设置中可开启）"。

### 2.5 空态 / 错误态

| 状态 | 呈现 |
|---|---|
| 无结果 | 插图 + "没有匹配的图片" + "试试减少标签" |
| 网络错误 | 错误卡片 + 错误码 + "重试" + "打开诊断" |
| 被 CF 拦 | 显示"正在验证 Cloudflare…"进度，不暴露技术细节 |
| 限流 | 顶部气泡"请求过快，已自动降速" |

## 3. 标签联想

- 输入 ≥ 2 字符、停止输入 300ms 触发。
- 数据源优先级：本地 `tag_cache`（命中前缀）→ 远端 `/tag.json?name=prefix*&limit=10`。
- 每项显示：标签名、类型（artist / copyright / character / general）、作品数。
- 键盘 `↑ ↓` 选择、`Tab` 补全为 chip、`Esc` 关闭。

| 类型 | 请求 |

## 5. 查看器

### 5.1 打开流程

`点击卡片 → 立即标记已看 → 并行加载 sample 与 file → sample 就绪后占位 → file 就绪后无缝替换`

- 打开后**始终自动懒加载原图**，不设体积阈值，也不提供“加载原图”按钮。
- 两种图片都经主进程流式下载（`images:fetch`），渲染层只接收字节并生成 `blob:` 展示；切图时按需加载，内存缓存最多 3 张。
- 加载进度：预览图进度在预览区居中，只显示一条无文本的进度条；原图进度固定在预览区右上角，显示百分比与“已加载 / 总量”，预览图就绪后位置不变。有 `Content-Length` 时显示确定进度；缺失时预览条与原图条均退化为不确定进度。
- 原图就绪后直接替换预览图（同一 `<img>` 切换 `blob:` 地址），不叠加渲染两张图。
- 失败：sample 失败且原图未就绪 → 画布中心错误提示（右上角原图进度继续展示）；原图失败但 sample 可用 → 保留 sample 并在右上角提示“原图加载失败”。
- 不预取相邻图片，避免无意义流量。

### 5.2 布局

- 图片区居中，支持滚轮缩放（以鼠标为锚点）、拖动、双击复位。
- 右侧信息栏（可收起）：尺寸、文件大小、评分、rating、来源链接、上传时间、标签（点击即搜）、操作按钮（下载 / 收藏 / 复制链接 / 在浏览器打开）。
- 底部：`已看 3 次 · 首次 2026-11-01`。

### 5.3 快捷键

| 键 | 行为 |
|---|---|
| `← / →` | 上一张 / 下一张（同时标记已看） |
| `Space` | 缩放复位 / 适应窗口 |
| `+ / -` | 放大 / 缩小 |
| `D` | 下载当前图 |
| `F` | 收藏 / 取消收藏 |
| `O` | 浏览器打开原图 |
| `Esc` | 关闭查看器 |

## 6. 已看标记（核心差异化功能）

### 6.1 标记规则

| 事件 | 标记 |
|---|---|
| 点击缩略图进入查看器 | ✅ |
| 查看器内切换上一张/下一张 | ✅ 逐张 |
| 从收藏页、下载页打开 | ✅ |
| 鼠标悬停、列表滚动出现 | ❌ |
| 下载完成 | ❌（记入"已下载"，独立状态） |
| 图片加载失败 | ✅（用户已表达查看意图，避免重复点击） |

### 6.2 视觉规范

不能只用颜色区分（色弱不友好），采用**透明度 + 图标**双编码：

| 状态 | 缩略图 | 角标（右上角，18×18，圆角 4，半透明底） |
|---|---|---|
| 已看 | `opacity: 0.55`，`filter: saturate(0.8)` | ✓ 灰蓝 `#6B7C93` |
| 已下载 | 正常 | ↓ 绿色 `#3FA96B` |
| 已收藏 | 正常 | ★ 琥珀 `#D9A441` |
| 已看 + hover | `opacity: 1` | ✓ 保留 |
| 组合 | 角标横向排列，最多 3 个 | — |

- 卡片右下角保留评分角标，不与之重叠。
- 加载态用骨架块，不使用"已看"样式，避免误判。

### 6.3 "隐藏已看"过滤

本地状态，服务器无感知，因此需**自动补页**：

```
while (可见项 < 一屏) and (连续补页 < 5):
    fetch(nextPage)
    append(filter(not viewed))
if 连续 5 页均无未看项:
    show("已跳过 N 张已看过的图片")
```

- 过滤开启时，顶部提示"已过滤 X 张已看"。
- 关闭过滤立即恢复完整列表（已加载数据不丢弃）。

### 6.4 清除记录

设置页提供"清除浏览记录"，选项：当前站点 / 全部。二次确认，操作后列表即时刷新。

## 7. 下载

### 7.1 入口

- 查看器 `D` 键或按钮：单张。
- 网格多选（`Shift` 连选、`Ctrl` 点选）：批量。
- 查询级"下载本查询前 N 张"：按当前筛选，默认 100 张，可改。

### 7.2 任务状态机

```
queued → downloading → verifying → done
                ↘ paused ↗
                ↘ failed（可重试）
```

### 7.3 命名模板

默认：`{site}/{rating}/{artist}/{md5}.{ext}`

| 变量 | 说明 |
|---|---|
| `{site}` | yande / konachan |
| `{rating}` | safe / questionable / explicit |
| `{artist}` | 首个 artist 标签，无则 `unknown` |
| `{copyright}` / `{character}` | 对应标签 |
| `{id}` / `{md5}` / `{ext}` | 标识与扩展名 |

非法字符替换为 `_`，长度上限 120；模板可在设置中修改。

### 7.4 去重与冲突

1. 先查 md5 是否已下载（数据库）。
2. 再查目标路径是否存在同名文件。
3. 存在且大小一致 → 跳过；不一致 → 追加 `(1)`。

### 7.5 批量确认

超过 50 张时弹确认框：数量、预估体积、目标目录。

## 8. 收藏

- 网格展示，按站点分组 tab。
- 支持按标签二次筛选、按收藏时间/评分排序。
- 收藏数据仅本地，不请求站点（避免触发限流）。

## 9. 设置

| 分组 | 项 |
|---|---|
| 常规 | 主题（暗/亮）、语言、启动时恢复上次查询 |
| 网络 | 代理（直连 / HTTP / SOCKS5 + 地址端口）、IP 映射表（域名→IP，可增删、可测试）、UA、清除 CF cookie / 重新验证 |
| 下载 | 目录、命名模板、并发 1–6、自动校验 md5、失败重试次数 |
| 内容 | R18 开关（开启需确认）、标签黑名单、隐藏已看默认值 |
| 隐私 | 清除浏览记录、清除缓存、导出/导入设置 |
| 诊断 | 见第 10 节 |

IP 映射表默认预置（用户可改）：

```
yande.re              198.251.89.183
files.yande.re        198.251.88.76
assets.yande.re       198.251.89.183   # 预览图域名，必须覆盖
konachan.com          104.21.4.105
files.konachan.com    104.21.4.105
```

- `assets.yande.re` 与主站同 IP，漏配会导致缩略图全部裂图
- konachan 备用 IP：`172.67.131.252`，主 IP 不通时切换
- 变更后提示"需重启应用生效"

## 10. 诊断页（P1）

一键检测，逐项输出结果与建议：

| 检测项 | 判定 | 建议文案 |
|---|---|---|
| DNS 解析 | 是否返回预期 IP | "DNS 被污染，已启用应用内 IP 映射" |
| TCP 443 | 是否可连 | "IP 不可达，请更换映射 IP 或配置代理" |
| TLS | 证书是否 `CN=站点域名` | "证书异常，可能存在中间人" |
| Cloudflare | 是否拿到 `cf_clearance` | "验证失败，请点击手动验证" |
| 代理 | 当前模式与连通性 | "代理不可用，已回退直连" |
| 限速 | 最近 5 分钟请求数 | — |

"一键复制报告"用于反馈问题。

## 13. 可访问性

- 所有状态角标带 `aria-label`（如"已看过"）。
- 键盘可完成搜索、浏览、查看、下载核心路径。
- 对比度满足 WCAG AA；不仅依赖颜色传达状态。

### 14.3 角标规则

- 顺序固定：`✓` → `↓` → `★`，最多 3 个，右上角横排
- 每个角标必须带 `aria-label`
- 已看态只改变缩略图透明度与饱和度，不改卡片尺寸，避免瀑布流跳动
