## 2. Mock Server 契约

位置：`tests/mock/server.ts`（T-10 已落地），监听 `127.0.0.1` 随机端口。

> T-10 已实现：`ok` / `429-3` / `challenge-once` / `challenge-always` / `timeout` 五个场景与 `/__stats`；非 `/__stats` 路径当前统一返回 `200 []`。fixtures 切片、`/file/:md5`、`slow-body` / `bad-md5` / `no-range` 由 T-12 / T-24 接入适配器与下载时补齐。

| 路由 | 行为 |
|---|---|
| `GET /post.json` | 读取 `fixtures/yande/posts-safe.json`，按 `limit`/`page` 切片；`tags` 含 `id:` 时只返回匹配项 |
| `GET /tag.json` | 返回 `fixtures/yande/tags.json` |
| `GET /post/popular_recent.json` | 返回 40 条（模拟真实行为，忽略 limit） |
| `GET /file/:md5` | 返回二进制流；支持按场景开关 Range |

场景开关（请求头 `x-scenario`）：

| 值 | 行为 |
|---|---|
| `ok`（默认） | 正常 200 |
| `429-3` | 前 3 次返回 429 + `Retry-After: 1`，之后 200 |
| `challenge-once` | 首次 403 + `fixtures/konachan/challenge-403.html`，之后 200 |
| `challenge-always` | 始终 403 挑战页 |
| `timeout` | 延迟 30s（触发超时分支） |
| `slow-body` | 分块慢速发送，用于测进度与取消 |
| `bad-md5` | 文件内容与 md5 不符 |
| `no-range` | 忽略 `Range`，始终返回 200 全量 |

断言辅助：`GET /__stats` 返回请求次数与时间戳，用于验证限速。

## 6. 测试数据规则

- 只使用 `fixtures/` 中的公开安全样本，不提交 R18 内容
- 时间相关断言使用固定 `created_at`，避免依赖当前时间
- 下载测试写入系统临时目录并在用后清理
- 真实站点测试仅在本地手工执行，频率不超过 1 次/分钟
