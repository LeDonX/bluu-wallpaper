## 4. Definition of Done

单个任务完成需同时满足：

1. 功能按验收标准手工验证通过
2. TypeScript 无错误，ESLint 无新增告警
3. 涉及解析/适配/命名的逻辑有单元测试
4. 无 `console.log` 残留（改用 electron-log）
5. IPC 参数有 zod 校验
6. 失败路径有用户可见的提示，不静默
7. 相关文档（PRD/设计/架构）如有偏差已同步
