## 2. 任务分解

### M0 项目骨架

| ID | 任务 | 产出 | 验收 |
|---|---|---|---|
| T-01 | 初始化 electron-vite + React + TS | 可 `dev` 启动窗口 | 窗口正常渲染，无报错 |
| T-02 | 工程规范 | ESLint + Prettier + TS strict + 路径别名 | `lint` / `typecheck` 通过 |
| T-03 | electron-builder 配置 | `electron-builder.yml`，NSIS x64 + portable | 产出 exe，可免管理员安装 |
| T-04 | 单实例与窗口基础 | 单实例锁、最小尺寸、暗色主题 | 重复启动不出现双窗口 |

### M1 网络内核

| ID | 任务 | 产出 | 验收 |
|---|---|---|---|
| T-05 | hostmap 模块 | 配置读写 + `host-resolver-rules` 注入 | 未配系统 hosts 时，konachan 域名解析到映射 IP |
| T-06 | session 管理 | 每站点 `persist:` session，保留默认 UA（DR-011） | 两站 cookie 互不影响，重启后保留 |
| T-07 | HTTP 层 | 限速令牌桶、超时、重试、错误分类 | 连续 50 次请求速率 ≤ 2/s；429 自动退避 |
| T-08 | CF 通行证 | 状态机 + 隐藏窗口 + cookie 轮询 | 首次访问 konachan 自动通过并复用 |
| T-09 | 代理支持 | HTTP/SOCKS5 应用与回退 | 代理不可用时自动回退直连并提示 |
| T-10 | 网络单测 | mock server 覆盖重试/限流/CF 识别 | 单测全绿，无真实站点依赖 |

## 4. Definition of Done

单个任务完成需同时满足：

1. 功能按验收标准手工验证通过
2. TypeScript 无错误，ESLint 无新增告警
3. 涉及解析/适配/命名的逻辑有单元测试
4. 无 `console.log` 残留（改用 electron-log）
5. IPC 参数有 zod 校验
6. 失败路径有用户可见的提示，不静默
7. 相关文档（PRD/设计/架构）如有偏差已同步
